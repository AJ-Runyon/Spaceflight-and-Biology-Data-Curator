11:54 AM to 1:30 PM - Planning the MVP
- Since this ETL pipeline is based around the OSDR API, I will be using their [RESTful API](RESTful%20API) for the extraction phase for the MVP.
- To enable machine learning with the data and flexibility in analysis, I will be using a data lake for the storage layer.
- for the transformation layer I will be using Polars. This is the idea if for for data scientist and machine learning use cases. 
- To save money on data storage, I will be using MinIO to connect to my private cloud server and allow me to switch to Amazon S3 later if desired.
- For the database layer, I will be using PostgreSQL and TimescaleDB. I will be using this because I plan to expand the project in order to accept telemetry data from live satellites using the SatNOGS DB API.
- For the data visualization layer, I will be using Streamlit, as it seems a better fit for the OSDR AWGs since it is a tool aimed at 
- For data orchestration, I will be using Apache Airflow.
- For Version 1.0 the pipeline will be OSDR API → Polars → MinIO/TimescaleDB → Streamlit.
